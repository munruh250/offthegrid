Map treatments

Same island, same noise-generated terrain as the hex study. Each of these reads what's revealed as a function of days survived — drag the ruler and watch names, paths and territories fill in. It's a small thing, but it makes the map itself an expression of "knowledge, not power."

None of these need to be exclusive. A watershed-basin world model with a corkboard-style journal for the recap screen, or range rings only during the stalk phase, are both reasonable. The technique doesn't have to be the same everywhere in the app — it has to be the same wherever the player is doing the same kind of thinking.

On performance. Terrain renders at reduced internal resolution and scales up — the same trick as the hex study — so the day ruler stays responsive with six canvases redrawing on every drag.

On touch targets. Node Network and Corkboard both place interactive points below 44px at this frame size. Either would need tap-nearest-centre with a generous radius, same caution as the hex grid.

The hex/terrain treatments from the last pass still stand if you want to compare any of these against that direction directly.
